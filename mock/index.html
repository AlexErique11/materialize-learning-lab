    Learning objective

    Explain whether each result change was caused by new source data or by mz_now() advancing logical time.

    SQL used in this lab

    CREATE MATERIALIZED VIEW order_alerts AS
SELECT o.order_id, o.customer
FROM orders AS o
LEFT JOIN payments AS p
  ON p.order_id = o.order_id
WHERE p.order_id IS NULL
  AND mz_now() >= o.created_at
      + INTERVAL '20 seconds'
  AND mz_now() < o.created_at
      + INTERVAL '75 seconds';
